# Lucky-Wheel

LuckyWheel is a powerful wheel of fortune designed with an extremely aesthetic, modern, and intuitive design. It offers unique and exceptional versatility, so much so that it can literally be run and spun even within plain text applications like Windows Notes or macOS TextEdit.

Main Features
Random selection and smooth animation with a modern and attractive user interface.

Aesthetic design and attention to detail for a pleasant visual experience.

Maximum versatility: lightweight and portable, it works anywhere, even within text editors like Windows Notes and macOS TextEdit.
